# SkyLanthanum

スカイランタン販売用のデジタルチケット表示ページと、当日受付用QRリーダーです。

- 購入者用チケット: `/tickets/`
- 受付リーダー: `/reader/`

受付リーダーでは、当日用の `reader_data.json` をiPad上で選択して読み込みます。

## 公開URL

- https://kankyo-com.github.io/SkyLanthanum/
- https://kankyo-com.github.io/SkyLanthanum/reader/

## 受付リーダー

- `reader_data.json` を選択すると自動でカメラを開始します。
- デフォルトは前面カメラです。
- `カメラ切替` で前面/背面を切り替えできます。
- QRコードを読み取るとビープ音を鳴らし、カメラを一旦停止して結果欄へスクロールします。
- `受渡済にする` でログに記録し、次の読み取り待ちへ戻ります。
- `キャンセルして次を読む` で記録せず次の読み取り待ちへ戻ります。
- 未受渡/受渡済/全体の人数と基数を表示します。
- 読み込み済み一覧で、`reader_data.json` 内の氏名、フリガナ、基数、受渡状態を確認できます。

## プライバシー

GitHub Pagesで公開するチケットページには、氏名、購入基数、PayPay取引番号下4桁を表示しません。
公開ページはQRコードとチケットIDだけを表示します。

氏名、購入基数、PayPay取引番号下4桁は、iPadでローカル読み込みする `reader_data.json` にのみ入れます。
`reader_data.json` はこのリポジトリへアップロードしないでください。
